# Sciospec COMInterface API

[Open the COMInterface API documentation](https://sciospec.github.io/cominterface/)

Select your instrument to find its command reference, request and response formats, annotated binary examples, and measurement workflows.

## Available references

| Product family | Instruments |
| --- | --- |
| Electrical impedance tomography (EIT) | EIT16, EIT32, EIT64, EIT128, EIT256 |
| Electrical impedance spectroscopy (EIS) | ISX-3, ISX-3mini, ISX-3 EIT, Medical Research ISX-3 |
| Potentiostats | CSX-64 |

Documentation for **LCR-1** and **LCR-3** is planned for the next release.

## Documentation versions

The online documentation shows the latest published version. Tagged versions can be downloaded as ZIP archives from [GitHub Tags](https://github.com/Sciospec/cominterface/tags).
